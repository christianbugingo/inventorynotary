# Inventory System

Offline inventory and sales software for shops, by COODIC LABS.

## Release 1.3.0 (macOS Apple Silicon)

Download **InventorySystem-1.3.0-macos-arm64.dmg** from the Releases page.

- Works on Macs with Apple Silicon (M1 or newer). Check: Apple menu → About This Mac → "Chip: Apple M…".
- Signed and notarized by Apple. Opens without security warnings.
- Works fully offline. No internet, no account, no data sent anywhere.
- Your data stays on your computer in `~/.inventorysystem`.

### Verify your download

Open Terminal in the folder with the downloaded file and run:

    shasum -a 256 InventorySystem-1.3.0-macos-arm64.dmg

The result must be:

    1a319414f8290f2c2858a16f2aaaf62620e8d2584554e0ae32f661775123fdb9

If it differs, do not open the file.

### Install

1. Open the .dmg and drag **Inventory System** to a folder on your Mac.
2. Open it. On first launch, accept the terms, create the administrator, save the recovery code, and choose the shop currency.
